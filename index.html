Copied - now paste it.
  1. Outlook (Windows or Mac): click Copy for Outlook → Outlook → Settings → Signatures → New → paste (Ctrl+V / Cmd+V) → Save. Set it as the default for new messages and replies.
  2. Gmail: click Copy for Gmail / iPhone → Settings → See all settings → Signature → Create new → paste → Save changes (bottom of the page).
  3. iPhone Mail: open this page on the phone, tap Copy for Gmail / iPhone → Settings → Apps → Mail → Signature → paste.
